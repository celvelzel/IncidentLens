## Implementation and contracts

Version 0.1.3. Public structured_call arguments and `(model, usage)` return remain unchanged; optional ProviderError.failure, recovery config/capability profiles and diagnostic fields are additive. Recovery defaults disabled; legacy generic single repair and legacy cancellation codes remain. Enabled cancellation propagates with measured usage.

Error taxonomy handles rate limits, server/network/timeouts, authentication, invalid request, explicit format incompatibility, JSON/schema/truncation and budget denials. Safe error codes only; no raw HTTP body, prompt, credentials or validation input is exported. Safe validation summaries expose schema-owned paths and reviewed error types.

Permit acquisition is atomic across total/stage budgets; request building precedes admission, then one physical dispatch is charged once. STOP interrupts backoff via existing active-task cancellation. Stage ContextVar and per-call measured delegate copies remove shared-guard interference. Unknown tokens stay incomplete/NULL; no hard token/output-cap guarantee is claimed. One correction at most; transport retries and correction obey a shared physical bound and global budget. Existing domain/citation/role/run guards reject forged evidence without repair or normalization.

Identity proposal binding is deferred. No runtime agents, production writes, V1.4/V1.5 behavior or new datasets were introduced. Model, initial prompts and evidence schemas stay fixed for comparison; generic versus targeted correction is explicitly documented and fingerprinted.

Engineering implementation and offline gates achieved; the intended real-provider reliability benefit remains **partially achieved / not demonstrated**. No RCA-quality claim or release publication follows from these results.

# Contract evolution and observed runtime boundaries

Provider public call/return signatures and ProviderError.code remain compatible. V1.3 adds optional failure, immutable capability profile, opt-in RecoveryConfig and safe diagnostics. Explicit constructor format overrides enabled capability; CLI then environment take higher precedence than YAML. Disabled mode preserves generic legacy repair/cancellation codes; enabled mode propagates native cancellation with usage attached.

A real attempt is serialized before admission, charged immediately before transport dispatch and reconciled exactly once. Short-lock permit acquisition checks global/stage/wall/known-token budgets atomically. Known token observers remain compatible; unknown usage and in-flight permits keep completeness false. Network failure may already cost provider-side generation; no zero-cost assumption. Output caps are not advertised as supported or sent without validation.

The stage ContextVar is per run/task; the guard is never swapped for another stage. MeasuredProvider captures guard/token observer and copies delegate per logical call. The provider captures callbacks once and carries logical_call_id in a task-local context, linking permits and diagnostic events. Retry/repair counters measure dispatched requests; scheduled actions remain separate events.

Syntax, schema and envelope/truncation failures are distinct. Envelope maps to UNKNOWN_PROVIDER_ERROR at the frozen FailureInfo boundary. Domain failures retain the existing authoritative role/run/evidence/citation error code and never trigger provider repair. Failure diagnostics are optional in existing trace details; no new top-level trace schema is required. Successful recovered transient faults do not become terminal MODEL_FAILURE events. Whole-task recovery remains TaskManager-owned and constrained by the same global permit issuer.

Mock call counts preserve legacy semantics; additive actual_http_requests is zero for Mock, logical calls remain measured. Configured transport attempts and corrections obey max_physical_attempts_per_call; max_structured_repairs is at most one. reserve_verifier_requests defaults zero for old-profile compatibility and applies only to recovery decisions when explicitly configured. min_request_time_seconds and safety_margin gate retry feasibility; hard wall cancellation remains at CallBudget.

# Future work and prerequisites

The immediate research prerequisite is a reviewed, independently sourced benchmark
with nonempty Dev/Test, accepted causal labels, semantic citation review, source-linked
family audits and trusted sealing. Then validate provider completion and usage coverage,
perform Dev-only calibration and preregister before untouched Test evaluation.

Cost calibration should estimate requests/tools plus uncertainty from saved Dev task
outcomes; enable tokens/latency only when coverage supports them. Uniform fallback is
currently conservative feasibility, not evidence of differentiated cost efficiency.
Evaluate lexical prediction contrast against reviewed outcomes and report paraphrase,
negation and absent-prediction failure slices before replacing it. Calibrated conditional
observation models would be required before making information-gain claims.

Evaluate candidate-cap truncation, whether required Verifier checks lose execution,
and source-gap bias using common visible snapshots and full saved failures. Durable
resume requires receipt-bound recovery, source/config lock validation and idempotent
output derivation; current explicit refusal is the supported behavior. Trace UI can
later render the same saved public records once CLI replay is sufficient and stable.

Tree communication, new specialist agents, RL/bandits, production monitoring and real
remediation are outside V1.5. They require separate authorization and evaluation;
current remediation remains PLAN_ONLY. Coding-agent commits do not prove individual
student contribution or research novelty.

## 目标与边界

提升多 agent 通过分工、共享发现、交叉纠错和资源调度获得的实际性能。重点比较相同资源上限下的正确率、错误归因、弃答和消耗，不预设多 agent 必须获胜。

改进必须基于通用机制，不按 incident 编号、已知 oracle、特定会话 ID 或固定配置数值返回答案。不通过削弱 Single 或给 Full 独占关键数据来制造优势。

3006–3010 已运行并已查看标签，后续仅作开发验证；不能再称为未见案例或盲测。历史运行与评分保留，不覆盖、不择优替换。

## 修改内容

| 模块 | 修改方向 | 对其他场景的作用 |
|---|---|---|
| 工具与检索记录 | 用工具能力定义类别清单，记录未查、成功为空、成功有记录、失败、部分完成；按服务与时间范围区分覆盖 | 防止把局部空结果当成全局检查完成 |
| 任务分配 | 根据剩余证据缺口和候选间的区分价值派任务；去重、按角色权限分配、保留收尾预算 | 专家互补，减少同质化和重复调用 |
| 共享证据整合 | 决策前核对已观察的机制、时序、症状、反证；展示相关记录，供模型决定是否支持候选 | 防止专家各有线索却没有合成答案 |
| 机制判断 | 比较配置、容量、并发、时长等关系，替代写死的特定数值；明确来源和条件，不读取标签 | 减少针对当前 benchmark 的规则适配 |
| Verifier | 聚焦有证据的错误归因、实质矛盾和竞争机制；每项阻断检查解释可能结果如何改变答案及能否获取 | 复核帮助收敛，避免索取现有工具无法提供的证明 |
| 分级答案与停止 | 区分已确认、最可能、证据不足；范围耗尽时总结当前解释，不重复同范围查询 | 保留有用判断，同时明确不确定性 |
| 提示词与协议 | 与上述机制同步，清楚区分观察、推断、假设、必要缺口和可选佐证 | 模型按通用流程工作，不依赖案例暗示 |

覆盖检查不是每例无条件扫描所有工具。根据公开服务、依赖、症状和已观察机制选择适用类别；因预算未检查必须显式保留为未覆盖，不能伪装已完成。所有查询照常消耗工具预算，禁止旁路读取证据或自动填入答案。

跨源记录不自动等于独立因果证明；同一原始数据拆成两条记录不能充当两个独立来源。缺少请求级关联不总是必须弃答，也不总能忽略，需说明它是否留下有证据支持的竞争原因。

### 0. 新模型兼容性与同模型基线

模型切换和架构修改不能混为同一个变量。

新模型极小探针通过后，先用 gpt-6-luna 运行当前未实施 A/B 的架构，五例 × 四组 × 一次，共 20 组，形成新模型基线。它与旧 5.6-luna 结果的差异只能称为模型/运行条件差异，不能算架构收益。

### A. 先改善取证与协作

实施检索覆盖记录、缺口驱动分工、共享证据核对；保留当前确认标准。

冻结 A 代码与提示词后，五例 × 四组 × 一次，共 20 组。重点检查关键证据获取率、重复查询、证据整合和根因判断是否改善。

### B. 再改善判断与停止

根据 A 的完整记录，制定并冻结通用机制判据、Verifier 阻断标准、分级答案和停止规则，再跑相同 20 组。不能在一个批次中途根据答案修改规则。

B 必须保留真实矛盾、数据缺失与竞争原因，不以降低弃答率作为唯一成功标准。

### 规模与预算

因增加同模型基线，后续开发计划由原 A/B 的 40 组变为总计 60 组，外加最多两种极小合成探针；本文件仅说明后续范围，不启动这些调用。

各组使用相同模型、low 推理、公开证据访问权限和总资源上限，保留现有预算：8 轮、64 次模型调用、40 次工具调用、7200 秒调查总时限、1200 秒单请求时限、最多 4 组并发。修正调用也计入预算，模型内部 HTTP 重试不可完整观测。

固定随机顺序，每组一次，不替换失败，不仅重跑不利结果。批次全部终态并锁定工件哈希后才评分；运行进程不输入 oracle。完整输入审计与更强文件隔离如需新增，应先作为独立实现项明确记录，不能声称已有绝对隔离。

## 公平性与性能解释

- Single、Fixed、无 Verifier、Full 共享基础工具、数据、通用机制判据和答案口径。Full 的额外收益应来自协作与独立复核；Single 保留自身工具能力和自我复核。
- Fixed 保持固定任务调度特征，不强行改成动态架构；用检索覆盖记录暴露其未覆盖类别，不隐式赠送额外工具调用。
- “最可能”不自动改写为“已确认”，不直接并入原 confirmed 根因成功率。若评价候选预测准确率，独立列出并同时报告覆盖率和错误率。
- 不把程序正常结束当成诊断正确，不从分母移除预算终止、CLI 失败或非法输出。
- 不与 5.6-luna 旧结果直接作架构因果归因；优先比较 6-luna 同模型基线、A、B。

## 输出与验收

每阶段输出冻结 manifest、逐项报告、调用/工具 ledger、来源引用、终止原因、事后评分和汇总对比。

指标包含：可识别例根因正确率、不可识别例正确弃答率、错误归因、最可能解释的独立预测指标、机制证据获取率、重复查询量、运行完成率、耗时、模型调用、工具调用和观测 token 下界。

期望：漏查减少、有依据的回答增加、无效追问减少，且错误归因不因放宽标准明显增加。Full 优势需同时报告收益和额外成本，不设必须达到特定优势的验收目标。

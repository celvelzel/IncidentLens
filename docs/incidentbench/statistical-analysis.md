# Predeclared statistical analysis

Primary contrasts compare full with strong-single and fixed-four on identifiable Core root correctness. Full versus dynamic-no-verifier is secondary. Technical failures score zero on applicable diagnostic denominators. Monitoring and OOD remain outside Core aggregates.

Repeated runs are averaged within case/variant before differences are formed. Matching repeat identities are required; duplicate or missing paired groups raise an error. Bootstrap draws resample entire scenario families with replacement, retaining every paired case difference in the selected family. The point estimate and each bootstrap draw use case-weighted differences. The seed and sample count are saved. Fewer than 20 families are explicitly exploratory; no significance claim follows from a narrow interval alone.

Exact binary discordance is supplementary and assumes independent cases, which family-related cases may violate. It is unavailable for repeat-averaged contrasts. Unknown tokens remain null in totals and completeness is reported. Citation existence measures observed same-incident IDs, not semantic support. Saved raw analysis calls no model; protocol/source/data lock verification must pass before recomputation.
